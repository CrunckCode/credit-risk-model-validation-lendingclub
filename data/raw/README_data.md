# Raw data

Source: LendingClub public loan data, 2007-2014 (466,285 loans, 75 columns), as used in the MQF "OOPs II" credit risk project.
The file is NOT committed (size and data terms). Set the path in `python/credit_validation/config.py` (`RAW_DIR`) or the env var `CV_RAW_DIR`.
Expected files in that folder: `loan_data_2007_2014.csv` and `loan_data_defaults.csv`.
Cite LendingClub as the data source. Do not redistribute the raw file.
