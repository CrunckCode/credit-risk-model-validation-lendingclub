Original-notebook defects (log as as-built review findings): LGD stage 1 applied as hard 0/1 labels (Final notebook cell 132); EAD summary prints the LGD stage-2 p-values (cell 113); LogisticRegression_with_p_values omits the intercept from the Fisher matrix and wraps a penalized sklearn fit (C=1) so Wald p-values are invalid; PD model uses mths_since_issue_d (loan age/censoring proxy); PD model loaded from pd_model.sav with no fitting code in the Final notebook and silent zero-fill of missing dummies; random 80/20 splits; EL uses lifetime PD over all loans (7.98% of funded, $531.9M). ## Validation design
Primary target: TARGET_BAD12 (fixed 12-month window), kept only where OBS12 (MOB_OBSERVED >= 12 + OBS_BUFFER). DEV = issues 2007-06..2012-12 (random 20% stratified HOLDOUT for in-time metrics and GBM calibration), OOT1 = 2013, OOT2 = 2014-01..2014-11, COMPLETE36 = 36-month loans issued up to 2012 with TARGET_LIFETIME. REPRO_TRAIN/TEST = random 80/20 on all rows (seed 42), lifetime target, reproduction only. DNMCP loans excluded (EXCLUDE_DNMCP). Two champion specs: SC_FULL (all application features incl. LC risk outputs) and SC_INDEP (INDEP_FEATURES, excludes grade/sub_grade/int_rate/installment) to test circularity.

## Data (Task A: data.py, targets.py, splits.py, features.py, binning.py, scorecard.py, repro_original.py)
- `data.load_loans(raw_dir=None, refresh=False, nrows=None) -> DataFrame` read with usecols, clean (percent strings, emp_length, term, 2-digit-year fix, home_ownership ANY/NONE/OTHER to OTHER), float32/category dtypes, parquet cache in config.INTERIM_DIR keyed by raw size+mtime. `data.load_defaults_reference() -> DataFrame[LOAN_ID, RECOVERY_RATE, CCF]`.
- `targets.add_targets(df) -> df`: MOB_LAST_PAY, MOB_OBSERVED, TARGET_BAD12/BAD24 (bad status AND MOB_LAST_PAY < window), OBS12/OBS24 (MOB_OBSERVED >= window + buffer), TARGET_LIFETIME (original definition), RECOVERY_RATE, RECOVERED_ANY, CCF ((funded - total_rec_prncp)/funded for charge-offs), NET_LOSS (funded - total_rec_prncp - recoveries + collection_recovery_fee for charge-offs else 0), ISSUE_MONTH, VINTAGE.
- `splits.time_splits(df, target=TARGET_BAD12) -> dict[str, DataFrame]` keys DEV_TRAIN, DEV_HOLDOUT, OOT1, OOT2, COMPLETE36, REPRO_TRAIN, REPRO_TEST; only OBS rows for the fixed-window target.
- `features.build_features(df) -> df` (adds TERM_M, EMP_YEARS, CREDIT_AGE_M, LOAN_TO_INC, PTI); `features.assert_no_leakage(feature_cols)` raises on POST_ORIGINATION, VINTAGE_PROXIES or any TARGET_COLUMNS.
- `binning.py`: `BinSpec`, `CatSpec`, `fit_numeric_bins(x, y, prebins=50, min_share=0.05, max_bins=8, monotone=True, special_values=())`, `fit_categorical_bins(x, y, min_share=0.02, max_groups=10)`, `woe_iv(bad, good, smooth=0.5)` with WoE = ln(%good/%bad) (logit coefficients negative), `iv_band(iv)`, `binning_report(specs) -> DataFrame[variable, bin, lo, hi, categories, n, bads, bad_rate, woe, iv_contrib]`. Bin rule: searchsorted side="left" (bin_lo exclusive, bin_hi inclusive); missing has its own bin; unseen categories go to the largest group.
- `scorecard.py`: `fit_scorecard(df, y_col, features, iv_min, p_max, vif_max, corr_max) -> Scorecard` (statsmodels Logit on WoE; iteratively drop wrong-sign, p > p_max, and the weaker of WoE pairs with |corr| > corr_max; report VIF); `Scorecard.margin/predict_pd/points(df)`, `export_points_table() -> DataFrame[variable, bin_id, lo, hi, categories, woe, coef, points]`; scaling Factor = PDO/ln2, Offset = BASE_SCORE - Factor*ln(BASE_ODDS), Points_ij = -(beta_j*WoE_ij + alpha/k)*Factor + Offset/k.
- `repro_original.py`: `ORIGINAL_COARSE_CLASSES` transcribed from cell 150/151; `reproduce_original_pd() -> dict` fit on REPRO_TRAIN with the dummy design, test AUC/Gini/KS with and without MTHS_SINCE_ISSUE_D (create it with reference date 2017-12 as the original did).

## Models and validation (Task B: stats_models.py, models.py, validation.py, stability.py, benchmark.py, lgd_ead.py, expected_loss.py, sensitivity.py)
- `stats_models.LogisticRegressionWithPValues` (composition; unpenalized, intercept included in X'VX; `.summary()` coef/SE/z/p; matches statsmodels to 1e-5), `LinearRegressionWithPValues(sklearn LinearRegression)` (inheritance via super().fit; df n-p-1; SE incl. intercept), `align_columns(df, columns)` (adds missing as 0 and logs a WARNING with the count).
- `models.ModelBundle` (name, kind in sc|xgb|lgbm|recal, features, estimator, calibrator, encoder; predict_pd, predict_margin, save, load); `fit_champions(splits) -> {sc_full, sc_indep}`; `fit_gbm(kind, train, holdout, features, monotone)` with config.MONOTONE_SIGNS (native categoricals; xgb one-hot); `tune_time_cv` (config.TUNE_ITER draws, expanding folds with validation years config.TUNE_VAL_YEARS); `calibrate(bundle, holdout, method="auto")` (Platt vs isotonic by Brier); `recalibrate_intercept(sc, oot1) -> bundle "sc_full_recal"`; `train_all(splits, quick=False) -> dict` keys sc_full, sc_indep, xgb, lgbm, sc_full_recal, repro_original (saves joblib to config.MODEL_DIR).
- `validation.py`/`stability.py`: auc, gini, ks, cap_table, decile_table, rank_order_inversions, calibration_table, hosmer_lemeshow (df g on OOT, g-2 in sample, power caveat for n > 100k), binomial_test_by_group (one-sided z plus Jeffreys Beta p-value), central_tendency, calibration_slope_intercept, brier (+skill), psi (deciles from dev, floor 1e-4), csi, psi_by_quarter, delong_test, bootstrap_ci (loan-level, capped at BOOT_ROW_CAP). Every test returns a dict with keys test, model, split, value, threshold, light (Green/Amber/Red) using config.THRESHOLDS. `run_battery(bundles, splits) -> DataFrame` writes outputs: validation_results.csv, benchmark.csv, deciles_<model>_<split>.csv, calibration_<model>_<split>.csv, grade_binomial_<split>.csv, psi_csi.csv, psi_by_quarter.csv, by_vintage.csv, scorecard_points.csv, binning_report.csv, model_meta.json.
- `benchmark.py`: AUC of sub_grade rank and of int_rate as scores, incremental Gini of SC_INDEP over sub_grade; Red if the scorecard does not beat sub_grade.
- `lgd_ead.py`/`expected_loss.py`: default population recomputed from raw and reconciled to loan_data_defaults.csv; LGD stage 1 Logit(any recovery) with p-values and stage 2 linear on RR given RR > 0 (t-tests, Breusch-Pagan), combined LGD = 1 - p1*RR2_hat (expected value; also compute the original hard-class version and compare); EAD = clip(CCF_hat,0,1)*funded; dev = defaults on loans issued up to 2012, OOT = 2013 defaults, 2014 reported not fitted; diagnostics (stage-1 AUC, R2/RMSE/MAE, actual-vs-predicted correlation, deciles, by grade, residual quantiles, recovery by default vintage); `el_backtest()` (a) 12-month EL12 = PD12*LGD*EAD vs realized NET_LOSS by grade x vintage 2010-2014 (2014 labelled partially unresolved), (b) lifetime on COMPLETE36 with a scorecard refit on 36-month loans issued 2007-2011 and tested on 2012 vs realized lifetime loss by grade, compared with the original 7.98% EL. Outputs lgd_stage1_coefs.csv, lgd_stage2_coefs.csv, ead_coefs.csv, lgd_ead_deciles.csv, el_backtest_12m.csv, el_backtest_lifetime.csv.
- `sensitivity.run_sensitivity(bundles, splits) -> DataFrame[scenario, model, mean_pd, delta_pd_pct, el, delta_el_pct, spearman_rank, share_band_moved]`: feature shocks on OOT1 (config.SENSITIVITY_SHOCKS and combined), PD multipliers, LGD add, target-definition variants (In Grace bad, 24-month window, DNMCP included), binning variants (min_share 3/5/10%, max_bins 5/8/12 with Gini and IV). Output sensitivity.csv.
